# Instrucciones del proyecto

- Este proyecto usa PlatformIO con un Arduino Uno R3 (`board = uno`).
- El código de aplicación vive en `src/` y la configuración de compilación en `platformio.ini`.
- Conserva el uso de la biblioteca Servo declarada en `platformio.ini`.
- Compila los cambios con `pio run` cuando PlatformIO esté disponible.
- No subas cambios al hardware conectado sin confirmar primero el puerto y el dispositivo.
